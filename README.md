## 🚀 วิธีการเริ่มต้นใช้งาน (Getting Started)

### วิธีที่ 1: รันด้วย Script อัตโนมัติ
```bash
./run.sh
```
ระบบจะทำการตรวจสอบและเปิด Server ที่ `http://localhost:8000`

### วิธีที่ 2: รันแยก Backend & Frontend
#### Backend:
```bash
python3 -m uvicorn backend.main:app --reload --port 8000
```
#### Frontend:
```bash
cd frontend
npm install
npm run dev
```
