# Planetary and zodiac paintings

Current planetary asset: `planet-devas-thai-v2.png`, superseding v1 below. See `THAI-DEVA-V2-PROMPT.md` for the user correction, exact prompts and crop geometry. V2 uses Thai day colors and symbolic origin motifs. Rahu black is now explicitly authorized by the user for Rahu art/swatches; the surrounding interface remains light. Exact mythic counts are accessible text, not a literal census of painted figures.

Created with the built-in ImageGen tool on 2026-09-13. These are original artistic interpretations inspired by Thai celestial imagery, not an assertion of canonical deity iconography. UI labels and calculated data determine the meaning; pictures are decorative.

- `planet-devas-v1.png`: 4 columns × 2 rows; Sun, Moon, Mars, Mercury / Jupiter, Venus, Saturn, True Node (Rahu).
- `zodiac-paintings-v1.png`: 4 columns × 3 rows; Aries, Taurus, Gemini, Cancer / Leo, Virgo, Libra, Scorpio / Sagittarius, Capricorn, Aquarius, Pisces.

The atlas layout is consumed through CSS so the original generated images remain unedited. Unknown planetary names must not receive an unrelated deity illustration. Original v1 palette: ivory, jade, gold, coral, muted violet. The v1 no-black constraint is superseded by the v2 Rahu exception.
