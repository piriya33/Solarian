# Solarian user journey

อัปเดต: 13 กันยายน 2026

Solarian เริ่มจากคำแนะนำสั้นที่นำไปใช้วางแผนได้ใน 4 มุมมอง: วันนี้ ปีนี้ ช่วงนี้ และตัวตน ผู้ใช้จึงเห็นสิ่งที่ควรทำและควรเลี่ยงก่อนสำรวจวงรอบ 108 ปีที่อยู่ต่อเนื่องลงมา โหราศาสตร์ทำหน้าที่เป็นกรอบตั้งคำถาม ผู้ใช้ยังต้องตรวจข้อเท็จจริง ต้นทุน และความเสี่ยงก่อนตัดสินใจ

## เส้นทางหลัก

1. **เข้าใจคุณค่าก่อนกรอกข้อมูล** — หน้าแรกอธิบายว่าระบบช่วยมองสัญญาณ ตรวจเหตุผล และวางก้าวถัดไป พร้อมระบุว่าไม่รับประกันเหตุการณ์หรือผลตอบแทน
2. **ยืนยันข้อมูลเกิด** — ผู้ใช้กรอกชื่อ วัน เวลา เมือง พิกัด และ UTC offset เอง ระบบไม่คำนวณจากช่องว่างและไม่แทนเวลาเกิดที่ไม่ทราบด้วยค่าประมาณ
3. **คำนวณข้อมูลจริงตามวันอ้างอิง** — frontend ส่งข้อมูลเกิดครบและ `reference_date` ของวันปัจจุบันในเขตเวลา Asia/Bangkok ไปยัง `/api/chart/calculate` พร้อมสถานะกำลังโหลด ข้อผิดพลาด และการยกเลิกคำขอเก่าเมื่อเปลี่ยนโปรไฟล์
4. **เริ่มจาก 4 มุมมองที่เข้าใจง่าย** — หลังคำนวณ ระบบเปิดแท็บ “วันนี้” เป็นค่าเริ่มต้น ผู้ใช้สลับไป “ปีนี้” “ช่วงนี้” และ “ตัวตน” ได้ แต่ละแท็บมีสรุปหนึ่งย่อหน้า สิ่งที่ควรทำ 1–3 ข้อ และสิ่งที่ควรเลี่ยง 1–3 ข้อ
5. **เห็นขอบเขตเวลาก่อนใช้คำแนะนำ** — “วันนี้” แสดงวันและเวลาที่คำนวณจริงในกรุงเทพฯ “ช่วงนี้” แสดงวันเริ่ม–สิ้นสุด “ปีนี้” ระบุอายุและวันที่อ้างอิง และ “ตัวตน” ระบุชัดว่าอ่านจากข้อมูลดวงกำเนิด ข้อความไม่อ้างความแน่นอนของเหตุการณ์
6. **เปิดที่มาเมื่อผู้ใช้ต้องการตรวจสอบ** — ปุ่ม “ดูที่มาของคำแนะนำ” แสดงแหล่งที่มาจากดวงอาทิตย์ ความสัมพันธ์ของดาว เรือน ดาวเจ้าเรือน และบริบทเวลา โดยเก็บรายละเอียดเหล่านี้ไว้พ้นจากลำดับอ่านแรก
7. **สำรวจแผน 108 ปีต่อจากคำแนะนำ** — เส้นเวลา 0–108 ปี ตัวเลื่อน ปุ่มก่อน/ถัดไป และช่องกรอกอายุพร้อมใช้งานโดยตรงใต้คำแนะนำ 4 มุมมอง
8. **อ่านแกนอาทิตย์และหลักฐานเชิงลึก** — ภายในส่วน 108 ปี ตำแหน่งดวงอาทิตย์กำเนิดและมุมสัมพันธ์ที่แตะดวงอาทิตย์ทั้งหมดมาก่อนสัญญาณรอง ภาพราศีเป็นภาพวาดเชิงศิลป์ ข้อมูลตัวเลขและชื่อราศียังคงเป็นแหล่งอ้างอิงหลัก
9. **ซูมปีที่เลือกเป็นสองชั้น**
   - ชั้นภาพใหญ่ใช้ดาวเสวยอายุและช่วงวันที่จริงเป็นบริบทระยะยาว
   - ชั้นจุดกระตุ้นใช้วิถีองศาฐาน 30° จากดวงอาทิตย์กำเนิด แสดงทุกดาวที่สูตรจัดเข้าปีที่เลือก พร้อม filter รายดาว
10. **แยกอายุทศนิยมออกจากช่องรายปี** — การ์ดจุดกระตุ้นแสดงอายุเชิงสัญลักษณ์สองตำแหน่งทศนิยมและบอกว่าช่องอายุบน slider เกิดจากการปัดค่าของสูตร อายุนี้ไม่ใช่วันเกิดเหตุการณ์หรือดาวจรจริง
11. **ตรวจ snapshot วันเกิดแยกต่างหาก** — ตำแหน่งดาวจรในส่วนแผน 108 ปีคำนวณ ณ วันเกิดของอายุที่เลือกหนึ่งวันและมีวันที่อ้างอิงชัด ไม่ถูกนำไปปนกับคำแนะนำ “วันนี้” หรืออ้างแทนทั้งปี
12. **บันทึกก้าวถัดไปหลังทบทวน** — ผู้ใช้เลือกการงาน การเงิน หรือการลงทุน แล้วบันทึกสิ่งที่จะทำพร้อมมุมมองที่อ่าน วันอ้างอิง ขอบเขตเวลา และข้อมูลที่ตรงกับมุมมองนั้นลงเบราว์เซอร์เครื่องนี้ ลบและย้อนคืนได้

## บัญชีและความต่อเนื่อง

- ผู้ใช้ทั่วไปคำนวณได้โดยไม่สร้างบัญชี
- การบันทึกโปรไฟล์ผ่านบัญชีเป็นการกระทำที่ผู้ใช้เลือกเอง ไม่มี paywall หรือ subscription
- การโหลดหน้าเดิมเก็บเฉพาะ `view`, `age` และ `focus` ใน URL โดยไม่ใส่วันเกิด เวลาเกิด หรือสถานที่เกิด
- เมื่อโหลดโปรไฟล์เดิมครั้งแรก ระบบคืนหน้าและอายุจาก URL; เมื่อเลือกคนใหม่หรือคำนวณข้อมูลเกิดใหม่ ระบบกลับสู่อายุปัจจุบันของคนนั้น
- โปรไฟล์เก่าที่ข้อมูลเกิดไม่ครบถูกปิดการคำนวณจนกว่าผู้ใช้จะตรวจและกรอกใหม่

## เส้นทางรองและขอบเขตปัจจุบัน

| เส้นทาง | พฤติกรรมปัจจุบัน |
|---|---|
| ข้อมูลดวง | เปิดวงล้อดวง ตารางดาว มุมสัมพันธ์ และดาวน์โหลด PDF จากข้อมูลจริง |
| ผู้ร่วมทาง | แยกคู่ครอง หุ้นส่วนธุรกิจ บริษัท และบุคคลกับบริษัท แต่ยังไม่แสดงผลวิเคราะห์ที่ engine ยังไม่รองรับ |
| ปาจื่อ | แสดงเป็นมุมมองทดลองที่ยังไม่เปิดในบทวิเคราะห์หลัก |
| วันนี้ | อยู่ในหน้าผลลัพธ์หลัก ใช้ `reference_date` ที่ระบุและ snapshot เวลา 12:00 น. Asia/Bangkok; ไม่ใช้ snapshot วันเกิดของแผน 108 ปีแทนวันนี้ |

## การสร้างรายได้ในอนาคต — ยังไม่เปิดใช้

ช่วง pilot ให้ผู้ใช้เข้าถึงคุณค่าหลักโดยไม่มีการเก็บเงินและไม่มี subscription เส้นทางที่เสนอสำหรับอนาคตคือ **เห็นคุณค่าครั้งแรกโดยไม่เสียเงิน → เลือกสร้างบัญชีเพื่อบันทึกโปรไฟล์ → กลับมาทบทวนสมุดแผน → เลือกเติมเวลาเข้าถึงการใช้งานผ่าน Bitcoin Lightning เมื่อผู้ใช้ต้องการ** การเติมเวลาต้องเกิดหลังจากผู้ใช้เห็นผลคำนวณและเข้าใจขอบเขตแล้ว ไม่มี countdown, scarcity หรือข้อความเร่งให้จ่าย

ตัวชี้วัดต่อไปนี้เป็นข้อเสนอสำหรับวัด journey และยังไม่ใช่ผลที่เกิดขึ้นจริง:

- อัตรากรอกข้อมูลครบและคำนวณสำเร็จ
- อัตราอ่านผลแล้วเลือกบันทึกโปรไฟล์หรือเพิ่มบันทึกในสมุดแผน
- อัตรากลับมาเปิดสมุดแผนภายใน 7 วัน
- หากเปิดการเติมเวลาในอนาคต ให้วัดการเลือกเติมเวลาหลังเกิดคุณค่าข้างต้น แยกจาก completion ของ journey ฟรี

## หลักความน่าเชื่อถือของวิถีองศาฐาน 30°

- สูตรเทียบองศาภายในราศีของดาวกับดวงอาทิตย์กำเนิดด้วย `(planet_longitude - sun_longitude) % 30` และวนซ้ำทุก 30 ปี
- การ์ดแสดงที่มาของค่าเมื่อ backend ส่งองศาดวงอาทิตย์ องศาดาว ราศี และองศากำเนิดมาให้
- จำนวนจุดกระตุ้นไม่บอกความรุนแรง และปีที่ไม่มีจุดกระตุ้นไม่ได้แปลว่าไม่มีเหตุการณ์สำคัญ
- คำอ่านและคำถามเป็นผลจากกฎของระบบ แยกจากตำแหน่งดาวที่คำนวณได้และจากหลักฐานทางการเงิน

## Mobile และ accessibility

- แท็บคำแนะนำ 4 มุมมองเรียงเป็น 2×2 บนมือถือ แต่ละปุ่มมีพื้นที่กดอย่างน้อย 44px และใช้ปุ่มลูกศร/Home/End บนคีย์บอร์ดเพื่อเปลี่ยนแท็บได้
- โครงหลักลดเป็นหนึ่งคอลัมน์บนมือถือ ภาพดาวและภาพราศีมีขนาดช่วยสร้างลำดับชั้นโดยไม่แทนชื่อที่อ่านได้
- กลุ่ม filter ใช้ปุ่มจริงพร้อม `aria-pressed`, wrap ได้ และมี target ขั้นต่ำ 44px
- Slider รองรับ keyboard และมีปุ่มก่อน/ถัดไปกับช่องกรอก 0–108 เป็นทางเลือก
- เนื้อหาเปลี่ยนตามอายุมี live region; dialog บัญชีปิดด้วย Escape และคืน focus ตามพฤติกรรม native dialog
- ตารางและวงล้อขั้นสูงถูกจำกัดใน container เพื่อไม่ให้เกิด page-level horizontal overflow ที่ 390px
